# Terrace arena export (Blender 5.2, blender Z up exported as glTF Y up; 1 unit = one cell spacing)
Files: arena.glb (1489 nodes, 26,450 tris, meshopt flag on, no textures, vertex colour COLOR_0 only), kit_arena.glb (one node per reusable kit mesh at origin: cell, marbles, pedestal, rings, arrow, post, wall), placements.json (mesh -> every node: name, loc (Blender xyz), rotz, scale, material), lights_camera.json.
Layout: cell centres blender (x = q + r/2, y = sqrt3/2 r), three.js x=x, z=-y; board top y=0 (dish top 0.07).
Nodes: scene_cell_00..60 (kit_cell_hex, one mesh), scene_slab_arena, scene_post_0..5, scene_col_plateau_* (kit_col_plateau_{moss,dust,slate}), scene_col_map_b{0,1,2}_* (kit_col_map_b<band>_<tint>_j<0-2>, 27 meshes, instanced), scene_tower_body_*/scene_tower_lamp_*, scene_outcrop_*, scene_wall_claim_*, scene_crew_*, scene_cairn_*, scene_sky_dome/sun/planet/cloud_00-15/hazeband, scene_ridge_0-2, scene_fogring_0-2, scene_fogline, scene_ao_plinth, scene_turnbar_*.
Kit: scene_marble_black_/white_ (kit_marble_*), scene_pedestal_* (kit_pedestal_flat, 0.04 high), scene_ring_select/target/lastmove*, scene_arrow_target_*.
Materials (7 used): kit_mat_vertexcolor (Principled, rough 0.85, base = COLOR_0), kit_mat_emissive (emission = COLOR_0, glows, turn bar), kit_mat_alpha_shadow and kit_mat_alpha_haze (COLOR_0 rgb + alpha, blended, no shadow), kit_mat_sky (emission = COLOR_0, sky dome/sun/planet), kit_mat_marble_black (Principled base #15161b, rough 0.2, spec 0.5, reflects sky), kit_mat_marble_white (diffuse = COLOR_0, soft per-channel tone clamp at #e8e4d6, i.e. 0.91, no specular).
Palette: dish #b4aa81 (measured #b6ab82), gap #2c3438, pedestal top #c9bf9c side #8d845f, rim Slate #4b4f55, plateau slate #6a7077, Moss #446957, Dust #877d65, caps Bone #d8d4c8, turn bar #7fd6e8, last move #d9822b. Light: sun #ffd9a8 energy 3.9, azimuth 25 left of camera axis at yaw 0, elevation 28 (disc at elevation 6); rim #7fd6e8; hemisphere #9db8d8 / #5a4636; no point lights. Camera fov 40, default pitch 50, distance 13.6 (6..18).
Not exported: overlays of the boss rows, hub, contact blob (use the pedestal; shadow disc is kit_shadow_disc in the .blend), hint ring, Col0 attribute (stripped).
